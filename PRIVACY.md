# AIClear Privacy Policy / Gizlilik Politikası

## English

**AIClear** is designed to run 100% locally in Mozilla Firefox without collecting, transmitting, or sharing any user data.

- **Data Collection:** None (`data_collection_permissions: none`). AIClear includes zero telemetry, zero analytics, zero crash reporting, and zero external network requests.
- **Conversation Content:** AIClear never reads, stores, logs, or transmits conversation message bodies, prompts, responses, files, or account credentials. It only reads sidebar item identifiers and display titles temporarily in memory so you can select conversations to archive or delete.
- **Local Storage:** Only your local extension preferences (`cooldownMs`, `confirmBeforeArchive`, `excludePinned`, `language`) are saved locally in Firefox storage (`browser.storage.local`).
- **Website Access:** AIClear activates only on `https://chatgpt.com/*`, `https://gemini.google.com/*`, and `https://claude.ai/*` using Firefox's minimal `storage` and `activeTab` permissions.

## Türkçe

**AIClear**, Mozilla Firefox içinde %100 yerel çalışacak şekilde tasarlanmıştır; hiçbir kullanıcı verisini toplamaz, dışarı aktarmaz veya paylaşmaz.

- **Veri Toplama:** Yok (`data_collection_permissions: none`). Telemetri, analitik, çökme raporu veya dış sunucu bağlantısı içermez.
- **Sohbet İçeriği:** AIClear sohbet mesaj gövdelerini, istemleri, yanıtları, dosyaları veya hesap kimlik bilgilerini asla okumaz, kaydetmez ve göndermez. Yalnızca seçim yapabilmeniz için kenar çubuğundaki öğe kimliklerini ve görünen başlıkları geçici olarak bellekte kullanır.
- **Yerel Depolama:** Firefox yerel depolamasında (`browser.storage.local`) yalnızca kullanıcı tercihleriniz (`cooldownMs`, `confirmBeforeArchive`, `excludePinned`, `language`) saklanır.
- **Site Erişimi:** Yalnızca `https://chatgpt.com/*`, `https://gemini.google.com/*` ve `https://claude.ai/*` adreslerinde, en düşük `storage` ve `activeTab` izinleriyle çalışır.
